# 2026-10-09 공급망·미디어 출시 게이트 업데이트

## 목적

자동 검사가 기술적 완성과 사람의 창작·권리·공개 결정을 섞어 PASS로 표시하지 않도록 세 경계를 분리했다.

## 구현

1. `audit-baseline.json` + `npm run audit:baseline`
   - 검토된 취약 패키지·권고 ID만 허용한다.
   - 신규 권고, 신규 취약 패키지, critical, high 6건 또는 moderate 3건 초과를 실패시킨다.
   - 현재 결과는 `PASS_WITH_HOLD`이며 취약점 0을 뜻하지 않는다.
2. `validateFinalMediaOutput`
   - 실제 파일 존재·크기, H.264/AAC, 계획 해상도, 타임라인 길이를 검사한다.
   - 성공과 다중 결함을 증명하는 음성 회귀 테스트를 추가했다.
3. `release-review.example.json` + `npm run validate:release`
   - 자산 출처·권리 근거·상업 이용·필수 저작자 표시를 기록한다.
   - 기술 검사, 창작 품질, 저작권, 최종 공개를 별도 판정한다.
   - `pending`은 HOLD, `rejected`나 증빙 누락은 FAIL이다.

## 실제 렌더 증거

- 로컬 실제 입력으로 계획 → ASS 자막 → 타이포그래피 렌더 → 최종 합성 전체 실행 완료
- 최종 MP4: 23,472,404바이트, 1920×1080, H.264/AAC, 195.967초
- 9구간 접촉표: 검은 프레임과 자막 누락은 관찰되지 않았고 한글 자막은 판독 가능
- 한 장의 배경 이미지가 전체 표본에 반복되므로 시각적 다양성과 최종 미학은 사람 검토 HOLD
- 입력·출력·접촉표는 Git 비추적이며 저장소에 포함하지 않는다.

## 남은 사람 결정

- 음악·가사·이미지의 소유권 또는 라이선스 증빙
- 상업 이용 가능 여부와 필요한 저작자 표시
- 가사 싱크, 장면 다양성, 감정 적합성, 최종 미학
- 실제 게시 채널과 최종 공개 승인
